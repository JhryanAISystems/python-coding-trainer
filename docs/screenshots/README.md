# Screenshots

This folder is a placeholder for the demo GIF/screenshots referenced in the
main [README.md](../../README.md). Claude Code can't capture real browser
screenshots in this environment, so add your own after running the app:

1. Run the app locally (`docker-compose up`, or the backend/frontend dev
   servers — see the README).
2. Capture:
   - `landing.png` — the landing page
   - `exercises.png` — the exercise browser with filters
   - `workspace.png` — an exercise workspace mid-solve, ideally showing a
     passing result
   - `dashboard.png` — the progress dashboard with charts
   - Optionally, a short screen recording turned into `demo.gif`
3. Drop the files in this folder using those names, then update the
   `<!-- screenshot placeholders -->` section in the root `README.md` to
   reference them (the markdown is already there, just uncomment/point it
   at the real files).
